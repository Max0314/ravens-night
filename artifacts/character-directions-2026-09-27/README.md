## 方向

- A：封面延伸 / 暗色古典油画；写实材质、细铜金拱框，与原封面最接近。
- B：手绘雕版 / 低饱和水彩；旧纸底和细密刻线，故事档案感。
- C：雾夜电影 / 半写实绘画；无装饰画框，月光和雾气营造空间纵深，偏写实。
- D：装饰艺术 / 哥特几何；平面形块与铜金装饰，更有成套卡牌感。

三个角色分别为洗衣妇（washerwoman）、猎魔人（slayer）、守鸦人（ravenkeeper）。每个角色以一致的年龄、发型、服装颜色和职业道具描述尽量保持身份；不是对同一底图进行严格换风格，因此存在轻微脸部、姿势差异。
