## 文件与尺寸约定

- `originals/<id>.png`：4张1086×1448 RGBA完整源图。
- `apps/web/public/assets/ravens/role-type-frames-v2/<id>.webp`：4张960×1280完整清晰档。
- 同目录 `<id>-small.webp`：4张240×320透明无损WebP，供索引小图；`manifest.json`包含源PNG与8张运行图的尺寸、SHA256和alpha事实。
- `offline-preview.png`：上排240像素宽原档，下排120像素宽裸框及人物合成，仅用于离线媒体核对，不是页面截图或真机验收。人物原图没有因此改写或烘焙边框。

已先检查v1的240×320缩略档确实存在。经手册会话确认，Guide会限制外盒宽度≤128 CSS像素、内部3:4框宽度≤120 CSS像素，竖屏430以下实际约117 CSS像素。因此v2沿用240×320档，至少2倍、常见手机约2.4–3倍采样；不再堆叠中间分辨率，也不让全部索引角色加载960档。

固定运行URL为 `/assets/ravens/role-type-frames-v2/{townsfolk,outsider,minion,demon}-small.webp`，完整档去掉`-small`。`role-art.ts`只将框根路径从v1改v2，公开类型映射/字段名不变，人物路径和未知身份规则不变。首页/详情/本人卡是否展示框不由该素材映射决定，本交付不重新接入这些页面。
