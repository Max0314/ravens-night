# 简约暗铜角色表小框 v3

2026-11-13 按用户手机反馈重新设计：v2过亮且纹饰过密，本批改用**手绘SVG路径**。只给角色表小图使用，不接首页、详情或本人身份卡，不改页面、共享组件/CSS、声音或城镇。v1/v2图片与URL完整保留。

## 实际设计变化

- 同一套薄暗铜轨道、平顺拱线与圆弧转角，主色`#51452f` / `#786344`，低对比、不加发光或亮金高光。
- 顶部中央完全去掉城镇、叶子、角冠等徽记。中央只有主框结构线，没有装饰图案；最上方中央开口留白。
- 四类只靠左右上角区别：镇民为城楼与尖窗，外来者为羽叶与可辨的双环绳结，爪牙为交缠主枝及少量大刺，恶魔为有指骨/膜面区分的蝠翼。角部小块黑铜哑面只用于隔开人物背景。
- 侧轨与底角不放纹样，不再沿轨道重复窗花/绳索/荆棘。透明脸区保持干净。

120像素独立审查指出初稿绳结偏小、荆棘像交叉线，已只加强关键轮廓并复审闭环；没有通过增加整体亮度或重堆金雕来补辨识。

## 来源、运行文件与重建

`source.mjs` 是可编辑矢量来源，完整保留共用轮廓、四类path坐标、笔宽和色值。未调用imagegen，没有栅格嵌入、外部图片、字体、滤镜或脚本。运行SVG本身也保留可编辑路径。

运行文件仅4份：`apps/web/public/assets/ravens/role-type-frames-v3/{townsfolk,outsider,minion,demon}.svg`，viewBox均为`0 0 240 320`，任意小图尺寸直接矢量缩放，不产生240/960多档副本。`manifest.json`记录来源、尺寸比例、字节数和每个SVG的SHA256；四份总计4628字节。

`role-art.ts`仅切换v3根路径和SVG后缀，`frameUrl`与`frameThumbnailUrl`共用同一URL，不返回冗余`frameSrcSet`。未知身份中性处理和人物路径不变。只同步既有目标用例的单SVG资源约定，不改变任何页面或身份权限。

重建：仓库根运行 `node artifacts/role-type-frames-v3-2026-11-13/source.mjs`，使用既有sharp离线渲染。只写v3运行目录及本交付目录样例，不重写v1/v2。

- `preview-120px.png`：4类各120×160，按镇民、外来者、爪牙、恶魔顺序，在`#12140f`暗背景与既有人物图上静态合成。
