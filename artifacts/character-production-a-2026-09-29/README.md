# 暗流涌动 · A 版正式角色画册

2026-09-29 根据用户选择“整套 A，执行”，将西式哥特、暗色古典油画与薄铜金拱框扩展为完整 22 个角色。封面原画与文案保持原样。洗衣妇、猎魔人、守鸦人直接采用已选的 A 版原图；其余 19 个角色以这三张作为视觉参考，分别生成并检查。

## 生成记录

使用内置 ImageGen。完整提示词、输入参考、输出来源与逐张视觉检查分别保存在 `town-prompts.json`、`mystic-prompts.json`、`shadow-prompts.json`；三张选定原图的记录保留于 `../character-directions-2026-09-27/prompts.json`。统一要求见 `ART-DIRECTION.md`。

检查涵盖职业道具、年龄与面孔区分、手部、画面边缘、画风一致性和文字污染。占卜师、处女及猩红女郎做过定向面容修正。

## 网页交付

执行 `pnpm art:build` 从完整原图生成以下资产，不裁切、不改色、不重绘：

- 22 张 960 × 1280 WebP：共 4,140,728 字节。
- 22 张 240 × 320 WebP 缩略图：共 252,122 字节。
- `apps/web/public/assets/ravens/portraits-a-v1/manifest.json` 记录源文件 SHA-256、尺寸、编码器和每张交付体积。

身份卡与详情使用响应式图片；角色索引只加载缩略图；未知角色采用中性封面。旧的四张角色图集已移除。手机采用完整比例呈现，避免裁掉人物的头部和道具。

## 验证

严格资产构建确认 22 个角色齐全。320、390、1440 像素视口检查画册、身份卡和角色手册，检查溢出、图片加载、隐藏身份、键盘焦点与缩略图请求。角色手册修复了轮询刷新夺取焦点和初始 Shift+Tab 焦点外逃，并增加回归测试。

最终验证：176 项测试通过（默认跳过 1 项需外部 PostgreSQL 的集成测试），类型检查与生产构建通过；4 项多人 Playwright 流程通过，覆盖完整对局、枪击全端同步与下毒私密性、私聊与房主转移、空房回收。首次端到端运行因本机磁盘不足导致 trace 写入失败，关闭 trace 后完整重跑通过。
