## 文件

- `originals/<role-id>.png`：22张最终原图，保留生成质量。
- `prompts.json`：统一规范和初始逐角色提示词。
- `final-prompts.json`：初始提示与最后修订提示，用内置 image_gen 生成/编辑。
- `generated-files.json`：本机生成输出定位，最终交付全部已复制到项目。
- `old-collection-hashes.json`：开始制作前的旧版素材指纹，用于确认旧版未变。
- `apps/web/public/assets/ravens/portraits-b-v2/manifest.json`：角色、源图SHA256、尺寸、交付体积和编码器记录。
