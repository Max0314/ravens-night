# 恶魔接触音修订 v5

两条420ms音轨复用版本化v3撕裂声；原声来自项目原创合成与已注明许可的Kenney CC0素材，详见 `../v1/SOURCES.md`、`../v3/manifest.json`。无新外部下载、影视声音、人声或结果音。

运行 `python scripts/build-contact-audio.py` 重建，需FFmpeg和NumPy。脚本验证v3源SHA，裁掉80ms起步，压缩动态、增强中频、保留短淡入/尾音；manifest记录完整处理链、源/输出SHA、时长、响度、起音、绝对峰与最强10ms RMS窗口中心。运行调度将该85ms能量接触点对齐1450/1750ms屏幕两刀、2050/2350ms目标两刀（cinematicTiming.demon），不是把文件开头当接触点。v1钢盾和昼夜钟声保持原文件。

私密动作仅按线上设置发声，线下仍静音；演示页临时绕过房间参与方式，不修改正式偏好。四刀仅确认动作已提交，不确认目标死亡。媒体数值检查不构成手机扬声器听感验收。
